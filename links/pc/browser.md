# Browser

## Extensions I use

- For everything:
  - Consent-o-matic - <https://consentomatic.au.dk>
- For movies/letterboxd:
  - Open Selected Links - <https://chromewebstore.google.com/detail/open-selected-links/hcihcignkpajeehfnomlncinacagapdf>
- For YouTube:
  - Sponsorblock - <https://sponsor.ajay.app>
    - Settings: Switch all "Disabled" to "Show in seek bar"
  - Return YouTube Dislike - <https://returnyoutubedislike.com>
  - Youtube-shorts block - <https://chromewebstore.google.com/detail/youtube-shorts-block/jiaopdjbehhjgokpphdfgmapkobbnmjp>
- For Firefox:
  - Containerise - <https://addons.mozilla.org/en-GB/firefox/addon/containerise/>
    - Settings:
      - Default container: enabled, Lifetime: Until last tab is closed
      - Other containers: Google, Meta, Microsoft, OtherSignedIn
