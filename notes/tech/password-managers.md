# Password Managers

Password managers:

- Always use password manager
- For cloud-based, use Bitwarden or 1Password (never Lastpass)
- For local, use gnu pass or kpassxc

Hardware security keys:

- Use for sensitive stuff

Passwords:

- Different passwords
- Random passwords
- High entropy (uppercase, lowercase, numbers, special characters)

2FA:

- Use TOTP / HOTP
- Never use Email
- Never use SMS
- Save recovery keys separately and securely
